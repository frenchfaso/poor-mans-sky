# Licenses and asset provenance

- Original C, shaders, Python/shell tools and documentation: MPL-2.0 (LICENSE).
- `third_party/SDL2/`: Simple DirectMedia Layer headers. Original zlib-style
  license/copyright notices are preserved in each file, including SDL.h.
  Embedded OpenGL headers may carry Khronos/Mesa notices; those notices and
  terms remain in place and are not replaced by the project's MPL license.
- `assets/ground-procedural.bmp` and `assets/rock-procedural.bmp`: generated by
  `tools/generate-materials.py`, seed 20260911. Original procedural materials,
  no photography, external models or downloaded textures. Generated outputs
  are covered by MPL-2.0 and recreated locally; not stored in Git.
- `assets/actor-materials.bmp`: original AI-generated material atlas created
  for this demo, not downloaded from an asset library. Distributed under
  MPL-2.0 to the extent applicable. Its generation description is in
  `assets/GENERAZIONE.md`. Ship meshes and vegetation are constructed in code.

The former Poly Haven photographs have been removed and are not included in
this repository. Runtime SDL2, OpenGL and optional GameMode are system libraries,
not bundled binaries.

- `assets/cloud-procedural.rgba`: original procedural atlas generated by
  `tools/generate-clouds.py`, seed 20260915, under MPL-2.0. Four density volumes
  are integrated offline into the existing 128x128 RGBA texture; no external
  texture or book source code is included.
